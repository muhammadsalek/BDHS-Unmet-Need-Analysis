This repository accompanies a peer-reviewed publication and provides analysis code, spatial workflows, derived outputs, manuscript tables/figures, and revision provenance for transparent scholarly communication.

Research question

<div align="center">

Among currently pregnant women in Bangladesh, is internet use associated with unmet need for family planning after accounting for relevant socio-demographic and contextual characteristics?

</div>

Study profile

Component

Specification

Study design

Cross-sectional analysis of nationally representative survey data

Data source

Bangladesh Demographic and Health Survey (BDHS) 2022

Population

Currently pregnant women aged 15–49 years

Analytic sample

4,370 women

Primary exposure

Internet use

Primary outcome

Unmet need for family planning

Statistical framework

Complex survey design with weighting, stratification, and clustering

Main model

Survey-weighted multivariable logistic regression

Effect measures

Crude and adjusted odds ratios with 95% confidence intervals

Spatial component

Division-level descriptive mapping across 8 divisions

Statistical software

Stata + R

Publication

BMC Women's Health (2026)

📌 Key Findings

<table>
<tr>
<td width="50%" valign="top">

Primary association

Internet use was associated with higher odds of unmet need for family planning in the adjusted model:

<div align="center">

aOR = 1.83

95% CI: 1.52–2.20

</div>

</td>
<td width="50%" valign="top">

Spatial heterogeneity

The study evaluated geographic variation across all 8 administrative divisions of Bangladesh using division-level prevalence estimates and choropleth visualization.

The highest raw prevalence was observed in Chattogram division.

</td>
</tr>
</table>

Selected finding

Adjusted estimate

Internet use → unmet need

aOR 1.83 (95% CI 1.52–2.20)

Early age at first birth (10–17 years)

aOR 2.70 (95% CI 1.91–3.82)

Maternal age 25–34 years

aOR 2.41 (95% CI 1.82–3.17)

No formal education

aOR 5.34 (95% CI 1.70–16.71)

Barishal division

aOR 3.24 (95% CI 1.99–5.28)

Rajshahi division

aOR 3.30 (95% CI 1.62–6.72)

Sylhet division

aOR 2.98 (95% CI 1.96–4.53)

[!IMPORTANT]
These estimates describe associations. Because the study is cross-sectional, the results should not be interpreted as causal effects.

[!CAUTION]
DHS micro-level data must not be redistributed. If descriptive_data.dta contains respondent-level DHS microdata or recoverable micro-level records, it should not be distributed publicly through this repository. A safer reproducibility pattern is to provide analysis code, derived aggregate outputs, and instructions that allow authorized DHS users to recreate the analysis dataset locally.

🚀 Reproduce the Analysis

Requirements

Stata 15+ for the statistical workflow

R 4.2+ for spatial visualization

Authorized access to the required BDHS 2022 survey files

1 · Clone the repository

git clone https://github.com/muhammadsalek/BDHS-Unmet-Need-Analysis.git
cd BDHS-Unmet-Need-Analysis

2 · Run the Stata analysis

cd "/path/to/BDHS-Unmet-Need-Analysis"
do Analysis.do

3 · Prepare the spatial outputs

do Spatials.do

4 · Generate spatial figures in R

source("Spatial_Figures.R")
